## Палитра

Все цвета - CSS custom properties в `:root` (`custom_y2k.css`), по коду в файлах
использовать только `var(--y2k-...)`.

| Переменная                    | Значение  | Роль                                          |
| ----------------------------- | --------- | --------------------------------------------- |
| `--y2k-bg-page`               | `#dcd2f2` | фон окна браузера (поля вокруг `.page-frame`) |
| `--y2k-bg-frame` / `--y2k-bg` | `#efe9fb` | фон рамки-«окна» сайта                        |
| `--y2k-border`                | `#8f76c4` | все разделители, пунктирные рамки             |
| `--y2k-accent-pink`           | `#d4537e` | акцент 1 (лого, часть панелей)                |
| `--y2k-accent-purple`         | `#7a5fc0` | акцент 2 (лого, ссылки-акценты)               |
| `--y2k-panel-yellow`          | `#fdf7d4` | фон панелей типа «пост»                       |
| `--y2k-panel-pink`            | `#fbe3ec` | фон панелей типа «питомец»                    |
| `--y2k-text`                  | `#2b2440` | основной текст                                |
| `--y2k-link`                  | `#378add` | ссылки                                        |

Добавление нового цвета - только через новую переменную с именем по роли
(`--y2k-<роль>`), не по названию цвета.

## Шрифты

| Шрифт         | Где                                         | Почему                                                   |
| ------------- | ------------------------------------------- | -------------------------------------------------------- |
| Pixelify Sans | `h1`–`h3`, `.navbar-brand`, `.panel-header` | пиксельная эстетика, только крупные акцентные надписи    |
| IBM Plex Sans | `body` (наследуется всем текстом)           | читаемость основного текста - постов, комментариев, форм |

Подключение - одной ссылкой Google Fonts в `<head>` `base.html`, с fallback-цепочкой
(`'IBM Plex Sans', 'Segoe UI', Tahoma, sans-serif`) на случай недоступности CDN.

Правило: пиксельный шрифт не используется для текста длиннее заголовка/лейбла -
не читается мелким кеглем.

## Обводки и разделители

- Пунктир точками (`border-style: dotted`) - внешняя рамка `.page-frame`
- Пунктир штрихами (`border-style: dashed`) - все внутренние разделители:
  граница шапки/футера, вертикальная черта между лого и меню (только от
  breakpoint `lg`, см. `Шаблоны_и_вёрстка.md`)

## Раскладка страницы

Контентная колонка ограничена `max-width: 1024px` и центрирована
(`margin: 0 auto`) - сознательное решение: комфортная длина строки
для чтения, отсылка к фикс-ширинным сайтам эпохи. Поля вокруг колонки -
место под декоративный тайл/пиксель-арт (пока не реализовано).

## Пиксель-арт (PNG)

- `image-rendering: pixelated` на всех декоративных PNG - иначе браузер
  сглаживает растянутый растр
- Размер декоративных элементов - фиксированный px, кратный нативному
  размеру арта (без дробного масштабирования)
- Экспорт из Figma - 1 пиксель арта = 1 пиксель файла, увеличение только через CSS

# Шаблоны и вёрстка: base.html

`base.html` - единственный корневой шаблон. Все страницы наследуются от него через
`{% extends "base.html" %}`

---

## Структура каркаса

```text
<body>
  .page-frame                    - рамка-«окно», max-width: 1024px, центрирована
    <header>                     - navbar: лого + меню + вход/выход
    .container-fluid
      .row
        <aside col-lg-2>         - left_sidebar
        <main col>               - content
        <aside col-lg-3>         - right_sidebar
    <footer>
```

Прижатие футера: `body` и `.page-frame` - флекс-колонки на всю высоту окна
(`d-flex flex-column`, `min-vh-100` / `flex-grow-1`), футер получает `mt-auto`.
Не переносить `mt-auto` без этой флекс-цепочки - работать не будет.

---

## Блоки наследования

| Блок | Обязателен? | Назначение |
| --- | --- | --- |
| `title` | нет, есть дефолт | `<title>` вкладки, дефолт - «Сумасшедший мопс» |
| `content` | да | тело страницы |
| `left_sidebar` | нет, есть дефолт | меню / поиск / хештеги. Пустой `{% block left_sidebar %}{% endblock left_sidebar %}` в дочернем шаблоне убирает колонку (логин, регистрация, просмотр поста, формы создания/редактирования - без сайдбаров) |
| `right_sidebar` | нет, есть дефолт | питомец недели / рейтинг / календарь ДР. Отключается так же, как `left_sidebar` |
| `extra_head` | нет | доп. `<link>`/`<meta>` конкретной страницы (напр. CSS мини-игры) |
| `extra_js` | нет | доп. `<script>` конкретной страницы, после общего bootstrap.bundle |

Наполнение `left_sidebar`/`right_sidebar` по умолчанию - задачи `posts`/`feed`
(хештеги, рейтинг, календарь), в `base.html` сейчас только точки расширения.

---

## Адаптивность

Breakpoint `lg` (992px) - общая точка перелома для всего каркаса:
- `d-none d-lg-block` на обоих `<aside>` - сайдбары видны только от 992px
- `navbar-expand-lg` - меню сворачивается в бургер до 992px
- вертикальный разделитель лого/меню (`border-left` на `.navbar-nav`) - тоже только от 992px, на мобильном меню вертикальное, разделитель там неуместен

Ниже 992px - три колонки схлопываются в одну (`main` на всю ширину).

## Как проверить каркас

Временный маршрут `/test/` → `TemplateView` → шаблон-наследник с содержимым
в `content`. Чек-лист:
1. Открывается без `TemplateDoesNotExist` / `NoReverseMatch`
2. `custom_y2k.css` отдаётся 200 (Network), стили применены
3. Футер у нижнего края прикреплен к нижней части экрана
4. <992px: сайдбары исчезают, бургер раскрывается по клику
